# site-src Layout

This folder is organized by the part of the site you are likely to edit.

- `home/`
  homepage-only source
- `projects/`
  project card data and the shared project detail template
- `publications/`
  publication card data
- `gallery/`
  gallery data and gallery page template
- `shared/`
  site-wide config, redirects, shared helpers, and shared templates

If you are adding content, start in the page-area folder first.
If you are changing repeated layout or document head behavior, use `shared/`.
