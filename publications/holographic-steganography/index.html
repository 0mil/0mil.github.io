Information hiding in holographic content

Computer-generated holograms are the content of emerging holographic displays, yet remain largely unexplored as steganographic carriers. Their phase patterns must form the intended image after optical propagation, so information hiding must account for reconstruction quality as well as phase fidelity.

We embed bits in the parameters of a saved explicit representation, after the hologram has been generated. A double-phase hologram is separated into its two checkerboard components and fitted with oscillatory 2D Gabor primitives. The resulting state supports both holographic reconstruction and keyed payload recovery, allowing hidden information to travel with represented holographic content.

From a phase pattern to a keyed representation

The pipeline separates representation fitting, optical sensitivity analysis, and keyed embedding. Sensitivity analysis is performed once per display setting; the fitted state is then modified for each payload.

  1. Fit the phase components. Unpack the checkerboard and fit each component with 2D Gabor primitives. A circular loss respects phase periodicity, and the fitted output is wrapped modulo 2π.
  2. Select a carrier optically. Perturb parameter families independently and measure the reconstructed image. This identifies effective log amplitude in the high-value component as the embedding carrier.
  3. Embed with a shared key. Keyed Quantization Index Modulation (QIM) encodes each bit by the parity of a quantized amplitude index. The low-value component remains unchanged.
  4. Recover from the saved state. The shared key regenerates carrier selection, ordering, and dithers from primitive identities. Decoding uses the saved parameters rather than the rendered phase or an optical capture.

Reconstruction quality at a fixed payload

The fixed 100-bit benchmark uses one centered 512 × 512 patch from each of 200 sources: 100 CLIC 2020 and 100 DIV2K images. Each patch is reinserted into its full hologram before propagation, and the focused reconstruction is compared with the clean hologram’s reconstruction.

PDA-PSNR measures aligned phase fidelity; PSNR, SSIM, and LPIPS-Alex measure holographic reconstruction quality. PSNR values are in dB. Higher is better except for LPIPS.

Gabor Splatting achieves the highest mean reconstruction PSNR and lowest LPIPS among the evaluated methods. Its PSNR gain over RoSteALS is 2.23 dB (95% CI: 1.98–2.49 dB), with higher PSNR on 173 of 200 sources. Their mean SSIM differs by only 0.001.

Gabor Splatting uses 16k primitives per component and 384k stored parameters per patch. GaussianImage-16k uses 256k parameters; GaussianImage-24k matches the 384k parameter budget. At equal stored parameter count, our reconstruction PSNR is 5.44 dB higher. The comparison matches parameters, not runtime.

How much distortion does embedding add?

Across 25–1,000 bits, embedding distortion remains below representation fitting error. On 100 CLIC sources, the end-to-end reconstruction PSNR changes by less than 0.001 dB over this range. Improving the representation is therefore the larger opportunity for improving image quality.

Optical validation

Physical display captures show comparable scene structure and local detail before and after 100-bit embedding under identical settings. This complements the simulated propagation benchmark with an optical check of the reconstructed content.

Scope and next steps

The experiments cover single-plane holograms. Extending the method to multiple depths requires preserving reconstruction quality at every plane. The current Gabor implementation is also substantially slower than GaussianImage.

The saved-state decoder recovers all 4,500 tested payloads after save and reload. Supplementary experiments also test primitive reordering, reduced-precision storage, and keyless detection. These evaluations apply to the tested protocols and classifiers.

Code and data will be released upon acceptance.
